Trạng thái: Đang kiểm tra…

Khóa lưu tại thư mục riêng của tài khoản máy tính, ngoài repository GitHub. Không gửi khóa lên ChatGPT.

Nghe thử tạo âm thanh qua dịch vụ Microsoft (có thể phát sinh chi phí theo gói Azure). Nút kiểm tra qua game chỉ hoạt động khi server game đã chạy và hỗ trợ provider Azure.

Để game thực sự dùng Azure: mở Admin trong game → Giọng đọc → Microsoft Azure Speech → chọn Nam Minh/Hoài My → Lưu → Nghe thử. Nếu bạn vừa cập nhật key, cần Khởi động lại game.
